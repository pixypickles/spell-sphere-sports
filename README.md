# 魔導球技 v2.37

v2.12 は、v2.8〜v2.11 の継ぎ足し修正をやめて、現在の試合部分を整理して再構築した版です。

## 修正
- 開始メニューを実際に縦スクロール可能な構造へ変更
- 全要素への `touch-action:none` を廃止し、ゲーム操作部だけに限定
- 敵3人の生成処理を単純化して固定
- ビギナー3チームの役割差を維持
- 壁配置を再設計し、下側に十分な通路を確保
- v2.12 表示

## 現在の敵チーム
- ブルームランナーズ：旗取り型
- ストーンウォールズ：守備型
- スターショッツ：射撃型

## キャッシュ対策
GitHub Pages / スマホChromeで旧 `game.js` や `style.css` が残る問題を避けるため、
v2.12から実行ファイル名をバージョン付きに変更しています。

- `game-v2.12.js`
- `style-v2.12.css`

index.html側にもクエリ文字列を付けています。

## v2.18

## v2.19

## v2.20

- CPU射撃役が止まり続けず、射程内でも左右へストレイフ移動
- 守備役も旗周辺を少し動きながら守る
- 旗取り役の攻めを少し強め、前の特攻感を一部復活
- ただし前方回避禁止・回避中投球禁止は維持
