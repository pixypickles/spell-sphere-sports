# 魔導球技 Beginner Prototype v2

## v2での変更
- 参考ゲームと同じく画面全体を使用し、中央をコート・左右を操作UI領域に変更
- 攻撃方向を上下ではなく左右に変更
- キャラクターを小さめに変更
- 旗は各チーム1本
- スティックのタッチ領域を広げ、pointer captureで安定化
- PC確認用に WASD / 矢印キー移動にも対応
- コート内は7枚の壁から開始
- 3対3、60秒、2本先取、全滅または旗取得
- 特殊技ボタンはまだピースのみ

`index.html` をブラウザで開いてください。


## v2.1 修正
- スマホで試合開始/次ラウンドボタンが反応しない場合がある問題を修正
- click依存をやめ、pointerupでも開始できるように変更
- 古い端末向けにCanvas roundRect依存を除去


## v2.2 更新
- 操作キャラに黄色いリング＋頭上マーカーを追加
- 主人公チームの服に斜めストライプ模様と胸章を追加
- 投げボタン長押し中に回転弾専用のチャージモーションを追加
- 回転弾は発射直後に横へ膨らみ、敵へ強く曲がる軌道へ修正
- 投げ・回避ボタンを横並びにし、特殊技2ボタンをその上へ配置


## v2.3 更新
- 敵味方の魔力弾がぶつかると、両方が相殺されるように変更
- これにより将来の連射弾に「弾幕を削る」「相手の弾を消す」役割を持たせられる
- 壁を全体的に薄く変更
- 中央の大型遮蔽物を、中が空洞の枠型に変更
- 外周側にも薄い縦壁を配置
- 将来の壁破壊弾・壁沿い弾・反射系特殊技を想定した形に調整


## v2.4 更新
- 壁配置が上側へ偏っていたため、上・中央・下の3レーンへ再配置
- 自陣・敵陣の旗付近の壁を90度回して横向きに修正
- スマホ横持ちでブラウザのアドレスバー等が出ていても、画面下部が切れにくい表示へ変更
- 画面左下に小さく `v2.4` を常時表示
- 起動画面でもバージョン番号を確認可能
