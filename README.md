# 魔導球技 - Beginner Cup Prototype

スマホ横持ち想定の、1人用3対3「魔法×競技雪合戦」プロトタイプです。

## 今入っているもの

- 3対3
- 2本先取
- 1ラウンド60秒
- 勝利条件
  - 敵3人を全員アウト
  - 敵陣の旗に触れる
- 通常弾：投げボタン短押し
- 回転弾：投げボタンを約0.18秒以上長押し
- 回避：スティック方向へ飛び込み＋短い無敵時間＋クールタイム
- 魔力
  - 弾を投げると消費
  - 自然回復
  - 自陣旗の近くで速めに回復
- 味方AIの役割を試合前に選択
  - サポート
  - 旗取り
  - 守備
  - 射撃
  - バランス
- 敵AI
- 特殊技ボタンは未実装で、押すと ✌️
- キャラクターは柔らかい魔導帽＋点の目
- 壁あり
- 外周寄りにも一部壁あり

## 起動方法

`index.html` をブラウザで開いてください。

ローカルサーバーを使う場合:

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

## スマホで試す

同じWi-FiにPCとスマホを接続して、PC側で

```bash
python -m http.server 8000 --bind 0.0.0.0
```

を実行し、スマホからPCのローカルIPアドレスの `:8000` にアクセスすると試せます。

## GitHubに置く場合

このフォルダをそのままリポジトリに入れて構いません。

構成:

```text
magic_dodgeball_beginner/
├─ index.html
├─ style.css
├─ game.js
└─ README.md
```

GitHub Pagesを有効にすればブラウザで公開テストもできます。
